## Порядок действий
1. Скачиваем и открываем в Cisco Packet Tracer файл `Lesson2Homework.pkt`
2. Добавляем фамилию и имя с помощью инструмента *Place Note (N)*
3. Соединим роутеры 0 и 1 с помощью инструмента *Copper Cross-Over* через гигабитные порты Ethernet
4. Подключим сервера, свитчи и ПК с помощью *Copper Straight-Through* через порты FastEthernet![[attachments/Pasted image 20250327214722.png]]
5. С устройства `PC-PT@192.168.1.5` выполним `ping` к роутеру (`192.168.1.1`):
   ```sh
   C:\>ping 192.168.1.1
	Pinging 192.168.1.1 with 32 bytes of data:
	Request timed out.
	Request timed out.
	Request timed out.
	Request timed out.

	Ping statistics for 192.168.1.1:
		Packets: Sent = 4, Received = 0, Lost = 4 (100% loss)
	 ```
	 Потеря пакетов свидетельствует об ошибках в сетевой конфигурации
6. На устройстве `192.168.1.5` меняем шлюз на `192.168.1.1`. Добавляем конфигурацию IP (Static) для этого же устройства.
7. Меняем соединения между хабами на *Copper Cross-Over*.
8. На роутере 0 меняем Bandwith на **Auto**.
9. Пингуем сервер с любого из ПК:
   ```sh
   C:\>ping 10.0.0.3
	Pinging 10.0.0.3 with 32 bytes of data:
	Reply from 10.0.0.3: bytes=32 time<1ms TTL=128
	Reply from 10.0.0.3: bytes=32 time<1ms TTL=128
	Reply from 10.0.0.3: bytes=32 time<1ms TTL=128
	Reply from 10.0.0.3: bytes=32 time<1ms TTL=128
	
	Ping statistics for 10.0.0.3:
		Packets: Sent = 4, Received = 4, Lost = 0 (0% loss),
	Approximate round trip times in milli-seconds:
		Minimum = 0ms, Maximum = 0ms, Average = 0ms
	 ```
